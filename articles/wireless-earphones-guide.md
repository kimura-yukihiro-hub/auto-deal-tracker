## まず決めたいこと：どこで、何に使うか

イヤホン選びでいちばん大事なのは、使う場面をはっきりさせることです。場面によって、重視するポイントが変わります。

| 使う場面 | 重視したいポイント |
|---|---|
| 電車・バスでの通勤 | ノイズキャンセリング、電池の持ち |
| 在宅ワーク・Web 会議 | マイクの聞き取りやすさ、長時間つけても疲れにくいか |
| ランニング・ジム | 外れにくさ、汗や水への強さ（防水）、周りの音が聞こえるか |
| 家でのんびり音楽・動画 | 音質、つけ心地 |
| ゲーム | 音の遅れの少なさ |

全部入りの高価なものを選ぶより、自分の使い方に合ったものを選ぶほうが、満足しやすく、無駄な出費も減らせます。

## 選び方1：耳に入れる形で選ぶ

| 形 | 特徴 | 向いている人 |
|---|---|---|
| カナル型（耳栓のように耳の穴に入れる） | 周りの音を遮りやすく、低い音も聞こえやすい。今の主流 | 通勤中や外出先で、音楽に集中したい人 |
| インナーイヤー型（耳の入り口に引っかける） | 圧迫感が少なく、周りの音も少し聞こえる | 耳に何かを入れる感じが苦手な人 |
| 耳をふさがないタイプ（オープンイヤー・骨伝導など） | 耳の穴をふさがないので、周りの音がよく聞こえる。音は周りに漏れやすい | ランニング中や、家で家族の声や呼び出しに気づきたい人 |
| 首かけ型（左右がコードでつながっている） | 外しても首にかかるので、なくしにくい | イヤホンを落としたり、なくしたりするのが心配な人 |

カナル型は、付属の「イヤーピース」（耳に入るゴムの部分）のサイズを変えるだけで、つけ心地や音の聞こえ方が大きく変わります。
買ったら、いくつかのサイズを試してみましょう。

## 選び方2：ノイズキャンセリングと外音取り込み

### ノイズキャンセリング（ANC）

電車の走る音やエアコンの音など、周りの雑音を打ち消して小さくしてくれる機能です。商品名や説明に「ANC」と書かれていることもあります。
音量を上げなくても聞こえやすくなるので、通勤中や、カフェなどで集中したいときに便利です。

ただし、次の点に注意しましょう。

- **周りの音が聞こえにくくなります。** 歩いているときや自転車に乗っているときは、車や人の気配に気づきにくく危険です。自転車に乗りながらのイヤホンの使用は、地域のルールで禁止されていることもあります
- 効き目の強さは商品によって大きく違います。気になる人は、レビューで「電車の中でどのくらい静かになるか」を確認しましょう

### 外音取り込み

イヤホンを付けたまま、周りの音をマイクで拾って聞こえるようにする機能です。
コンビニのレジや駅のアナウンスなど、イヤホンを外さずに会話や音を聞きたいときに便利です。
ノイズキャンセリング付きのイヤホンには、この機能もついていることが多いです。

## 選び方3：電池の持ちは「本体」と「ケース込み」を分けて見る

ワイヤレスイヤホンの電池の持ちは、たいてい2つの数字で書かれています。

- **イヤホン本体だけで何時間使えるか**：1回の連続再生の目安。通勤の往復や、長い会議に足りるかを確認します
- **充電ケース込みで何時間使えるか**：ケースで何回か充電し直したときの合計。外出先で充電しなくても何日もつかの目安です

例えば「最大48時間再生」と大きく書かれていても、それはケース込みの合計で、本体だけでは数時間ということがよくあります。
長い会議や長時間の移動で使うなら、本体だけの時間を必ず確認しましょう。
また、ノイズキャンセリングをオンにすると、電池の持ちが短くなることが多いです。

充電ケースがワイヤレス充電に対応していると、スマホと一緒に置くだけで充電できて便利です。
ワイヤレス充電器の選び方は「[ワイヤレス充電器の選び方 置くだけ充電で失敗しないためのチェックポイント](/articles/wireless-charger-guide/)」にまとめています。

## 選び方4：通話・Web 会議で使うならマイクと「マルチポイント」

在宅ワークで Web 会議に使うなら、音楽を聴くときとは別のポイントがあります。

- **マイクの聞き取りやすさ**：自分の声が相手にどう聞こえるかは、イヤホンによって差があります。「通話時のノイズ低減」などの機能があると、周りの音を抑えて声を届けやすくなります。レビューで「通話の相手に声が聞き取りやすいと言われた」などの声を確認しましょう
- **マルチポイント**：スマホとパソコンなど、2台に同時につないでおける機能です。パソコンで会議をしていて、スマホに電話がかかってきたときも、つなぎ直さずに切り替えられます
- **長時間のつけ心地**：何時間も会議が続く日は、軽くて耳が痛くなりにくいものが向いています

耳に長時間入れても違和感ないものがいいですよね。

## 選び方5：iPhone・Android との相性

ワイヤレスイヤホンは、基本的にどのスマホでも使えます。ただ、スマホと同じメーカーのものを選ぶと便利な機能が増えます。

- **iPhone なら AirPods**：iPhone の近くでケースを開けるだけでつながる、iPad や Mac との切り替えが楽、なくしたときに「探す」アプリで場所を確かめられる、などの便利さがあります
- **Android なら、スマホと同じメーカーのイヤホン**：例えば Google Pixel と Pixel Buds、Galaxy と Galaxy Buds のように、つなぐのが簡単になったり、専用の機能が使えたりします

### 音質にこだわるなら「コーデック」も確認

コーデックは、スマホからイヤホンへ音を送るときの「送り方」の種類です。対応するコーデックによって、音質や音の遅れが変わります。

| コーデック | 特徴 |
|---|---|
| SBC | すべてのワイヤレスイヤホンが対応している基本の送り方 |
| AAC | iPhone が対応している送り方。iPhone で使うなら AAC 対応だと安心 |
| aptX・LDAC など | 主に Android で使える、より高音質な送り方。スマホとイヤホンの両方が対応している必要があります |

ただし、普段の音楽や動画を楽しむくらいなら、コーデックの違いを気にしすぎる必要はありません。
音質を重視したい人や、ゲームで音の遅れが気になる人は確認してみましょう。

## 買う前のチェックポイント

1. **使う場面に合った形か**（通勤ならカナル型、ランニングなら外れにくいものや耳をふさがないタイプなど）
2. **本体だけで何時間使えるか**（ケース込みの時間だけで判断しない）
3. **防水の性能**（運動で使うなら「IPX4」など、汗や水しぶきに強いことを表す表示を確認。数字が大きいほど水に強い）
4. **技適マークがあるか**（日本で Bluetooth 機器を使うには、電波法の基準を満たしたことを示す「技適マーク」が必要です。海外から直接届く格安品には、付いていないものがあるので注意しましょう）
5. **レビューの数と内容**（「片耳だけ聞こえなくなる」「すぐ接続が切れる」などの声が多くないか）
6. **メーカー保証と、片耳だけなくしたときの対応**（片耳だけ買い足せるメーカーもあります）

## まとめ

- まずは「どこで、何に使うか」を決める
- 耳に入れる形（カナル型・インナーイヤー型・耳をふさがないタイプ・首かけ型）を、使う場面に合わせて選ぶ
- 通勤ならノイズキャンセリング、ただし歩いているときは周りの音に注意する
- 電池の持ちは「本体だけ」の時間を確認する
- Web 会議に使うなら、マイクの聞き取りやすさとマルチポイントを確認する
- iPhone なら AAC 対応、スマホと同じメーカーのイヤホンなら便利な機能が増える

セールの価格や在庫は短時間で変わることがあります。購入する前に、必ず各ストアのページで最新の価格と条件を確認してください。
