ノートパソコンは、仕事にも、調べものや動画を見るなどの普段使いにも欠かせない道具です。
ただ、「CPU」「メモリ」「SSD」など見慣れない言葉が多く、値段も数万円から数十万円まで幅があるので、どれを選べばいいか迷いやすい製品でもあります。

この記事では、ノートパソコンを選ぶときに見るポイントを、詳しくない人にもわかるようにまとめました。

【編集者メモ：ノートパソコンをどんな場面で使いたいか（仕事・在宅ワーク・普段使いなど）や、買い替えを考えている理由を一言追記】

## 選び方1：持ち運ぶかどうかで「画面の大きさ」と「重さ」を決める

まずは、パソコンを持ち歩くかどうかを考えましょう。画面が大きいほど見やすくなりますが、重くなります。

| 使い方 | 画面の大きさの目安 | 重さの目安 |
|---|---|---|
| 毎日持ち歩く（通勤・出張・カフェなど） | 13〜14インチ | 1.3kg 以下 |
| ときどき持ち出す | 14インチ | 1.5kg くらいまで |
| 家や職場の机でほぼ動かさない | 15〜16インチ | 重さはあまり気にしなくてよい |

毎日持ち歩くなら、カタログの重さも確認しましょう。1kg 前後の軽いモデルもあります。
家で使う場合は、画面が大きく、キーボードに数字を打つキー（テンキー）が付いたモデルを選ぶと、表計算などがしやすくなります。

## 選び方2：「CPU」は名前の数字で性能の目安がわかる

CPU は、パソコンの頭脳にあたる部品で、処理の速さに関わります。
名前に入っている数字（3・5・7・9）が大きいほど高性能で、値段も高くなります。

| 用途 | CPU の目安 |
|---|---|
| ネット・メール・文書作成・動画を見る | Intel Core Ultra 5 / Core i5、AMD Ryzen 5、Apple M シリーズ |
| 写真の編集や、たくさんのアプリを同時に使う仕事 | Intel Core Ultra 7 / Core i7、AMD Ryzen 7 |

とても安いモデルには、「Celeron」や「Intel N100」などの、性能を抑えた CPU が使われていることがあります。
ネットを見る程度なら使えますが、仕事で長く使うなら、上の表の「5」以上のクラスを選ぶと安心です。

## 選び方3：「メモリ」は 16GB がおすすめ

メモリは、作業をするときの「机の広さ」にたとえられます。広いほど、たくさんのアプリやブラウザのタブを同時に開いても動きが遅くなりにくくなります。

- **16GB**：今のおすすめの目安。仕事でも普段使いでも、たいていの使い方で困りません
- **8GB**：ネットやメール中心なら使えますが、ブラウザのタブをたくさん開くと遅くなりやすくなります
- **32GB 以上**：動画の編集や、本格的なゲームをする人向け

ノートパソコンの多くは、買ったあとにメモリを増やすことができません。迷ったら 16GB を選んでおくと、長く使えます。

## 選び方4：保存容量は「SSD 256GB 以上」を選ぶ

写真や書類などのデータをしまっておく場所が「ストレージ」です。今のノートパソコンは、読み書きが速い「SSD」が主流です。

- **256GB**：書類やネット中心で、写真や動画はあまり保存しない人
- **512GB 以上**：スマホの写真や動画をパソコンにも保存したい人

安いモデルの中には、保存容量が少ない（128GB など）ものや、SSD より遅い「eMMC」を使ったものもあります。買う前に確認しましょう。

## 選び方5：Windows・Mac・Chromebook の違いを知っておく

| 種類 | 向いている人 | 気をつけること |
|---|---|---|
| Windows | 仕事で使う人。会社や学校と同じソフトを使いたい人 | 機種がとても多いので、CPU・メモリ・SSD を見て選ぶ |
| Mac（MacBook） | iPhone や iPad を使っている人。写真や動画の編集をしたい人 | 会社で決められている Windows 用のソフトが使えないことがある |
| Chromebook | ネットとメール中心で、安く買いたい人 | Windows 用のソフトは使えない。ほとんどの作業をネット上で行う |

仕事で使う場合は、会社や取引先で使っているソフトが動くかどうかを、先に確認しておきましょう。

## 選び方6：充電と端子を確認する

外出先で使うことが多い人は、次の点を確認しておくと便利です。

- **USB-C で充電できるか**：USB-C で充電できるモデルなら、スマホと充電器をまとめられることがあります。ただし、パソコンを充電するには、パソコンに合った出力（W 数）の充電器が必要です。パソコンに付いている充電器の W 数を目安にしましょう
- **バッテリーの持ち**：カタログに書かれている駆動時間は、決められた条件で測った数字です。実際の使い方では、それより短くなることが多いと考えておきましょう
- **必要な端子があるか**：会議室のモニターやプロジェクターにつなぐなら HDMI、USB メモリを使うなら USB-A など、よく使う端子が本体にあるか確認しましょう

モバイルバッテリーでノートパソコンを充電したい場合は、[モバイルバッテリーの選び方](/articles/mobile-battery-guide/)も参考にしてください。

## 買う前のチェックポイント

1. **何に使うかを決める**（仕事・普段使い・写真の編集など）
2. **持ち歩くかどうかで、画面の大きさと重さを決める**
3. **CPU は「5」以上、メモリは 16GB、SSD は 256GB 以上を目安にする**
4. **Windows・Mac・Chromebook のどれにするか決める**（仕事で使うソフトが動くか確認）
5. **Office（Word・Excel）が付いているか確認する**：付いているモデルは、その分値段が高くなります。会社から使えるものが用意されている場合などは、付いていないモデルでも困らないことがあります
6. **保証の期間とサポートを確認する**

## まとめ

- 持ち歩くなら 13〜14インチ・1.3kg 以下、家で使うなら 15〜16インチが目安
- CPU は名前の数字が「5」以上、メモリは 16GB、SSD は 256GB 以上を選ぶと安心
- 仕事で使うなら、必要なソフトが動くか（Windows・Mac・Chromebook）を確認する
- USB-C 充電・バッテリーの持ち・端子も、使い方に合わせて確認する

セールの価格や在庫は短時間で変わることがあります。購入する前に、必ず各ストアのページで最新の価格と条件を確認してください。
